# Security Policy

## Supported Versions

Zen Notebook currently provides security updates for its latest release only.

| Version | Supported |
|---|---|
| Latest release | :white_check_mark: |
| Older releases | :x: |
| Development versions | :x: |

Users are encouraged to update to the latest release to receive available security fixes.

## Reporting a Vulnerability

If you discover a potential security vulnerability in Zen Notebook, please report it responsibly.

**How to report:**

1. Check whether private vulnerability reporting is available in the repository's **Security** tab.
2. If it is available, use that feature to submit your report privately.
3. If private reporting is unavailable, contact the repository maintainer through their GitHub profile and request a private reporting channel.

Please do not publish vulnerability details or exploitable code in public issues before the vulnerability has been investigated.

### What to Include

When reporting a vulnerability, please provide:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The affected version or component.
- The potential security impact.
- Any relevant screenshots, logs, or proof-of-concept material.

### What to Expect

- Reports will be reviewed as soon as reasonably possible.
- You may be contacted for additional information.
- If the vulnerability is confirmed, the project will work toward an appropriate fix.
- You will be informed when the issue has been addressed or if it is not considered a security vulnerability.

Thank you for helping keep Zen Notebook and its users safe.

**Responsible security reporting is appreciated.**
